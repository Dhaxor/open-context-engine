Codebase context for Windsurf's Cascade

Give Cascade the same retrieval your other tools get: hybrid code search, symbol lookups and a repo map over a local index of the project, added to Windsurf's MCP config by one command.

Updated 16 Nov 2026

step 1 · 1 minInstall

npm install -g @dhaxor/open-context     # Node 22+

step 2 · 30 sAdd it to Windsurf

Windsurf keeps MCP servers in one global file, so run this in the project you want Cascade to search:

cd /path/to/your/repo
oce mcp install windsurf

It merges this entry into ~/.codeium/windsurf/mcp_config.json, pinned to the project's absolute path:

{
  "mcpServers": {
    "open-context": {
      "command": "oce",
      "args": ["mcp", "--workspace", "/path/to/your/repo"]
    }
  }
}

Other servers in the file are kept; an unreadable file is left untouched and the entry is printed for you to paste. --print previews, --remove undoes.

step 3 · 1 minRefresh and verify

In Cascade's MCP settings, refresh the server list: open-context should appear with its tools. Ask Cascade a question only your code can answer — it should call codebase-retrieval and cite real files.

More than one project

Because the config is global, give each project its own server name:

cd ~/code/api   && oce mcp install windsurf --name oce-api
cd ~/code/web   && oce mcp install windsurf --name oce-web

What Cascade gets

  • codebase-retrieval — hybrid BM25 + vector search over AST-aware chunks, expanded along the code graph.
  • repo-map, find-symbol-definition, find-symbol-references, read-file, list-files.
  • Memory tools that carry facts about your codebase across sessions — see agent memory.

Every tool reads the same local index your Claude Code, Cursor and VS Code setups use. The full tool list is on the MCP server page.

Troubleshooting

  • The server doesn't start — run oce mcp --workspace /path/to/your/repo in a terminal to see the error Windsurf sees.
  • oce not found — re-run with --npx so Windsurf starts it through npx -y @dhaxor/open-context.
  • Search seems keyword-only — oce status; then oce setup --embeddings local for in-process semantic search.
