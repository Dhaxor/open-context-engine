Changelog

Every release, what shipped, and why. Install the latest with npm install -g @dhaxor/open-context.

0.7.1 2026-11-08

  • Listed in the official MCP Registry as io.github.Dhaxor/open-context-engine — the package now carries the registry-required mcpName field, so clients can discover and install it straight from the canonical registry.
  • repo-map — a budgeted symbol outline of the whole codebase, exposed as an MCP tool and via oce map, so agents can orient before diving in.
  • OS-sandboxed shell execution — the agent's shell tool runs under Seatbelt on macOS and bubblewrap on Linux.
  • OCE review agent — a GitHub Action that reviews PRs grounded in the indexed codebase.
  • AGENTS.md support — agent guidelines read from AGENTS.md / CLAUDE.md / .cursorrules into the system prompt.
  • Guides hub — opencontextengine.com/guides plus field guides on agentic workflows, code RAG, MCP, semantic code search, RAG vs fine-tuning, and context engineering.

0.7.0 2026-11-01

  • The agentic sidebar ships — the extension's chat is rebuilt on the Trace stack: an evidence rail in the editor, agent edits with per-file diffs and undo, and a live index underneath.

0.6.0 2026-10-27

  • Class declarations indexed; exact symbol declarations promoted in ranking — retrieval now surfaces the declaration chunk for class-shaped questions and exact-match symbol queries.
  • Symbol-tool capability indicator in the extension, backed by a real language-server validation pass (tsserver files opened before querying).
  • Third external gold set — gin v1.10.0 (Go), 26 cases — with nightly CI running all gold sets plus the agent eval suite, and the benchmarks page auto-refreshing from committed baselines.
  • License hardening — rate-limited activation endpoint and Polar seat enforcement.

0.5.0 2026-10-27

  • npm publishes with zero secrets — Trusted Publishing (OIDC): the registry trusts the repository's workflow directly; no token to rotate or leak.
  • Adaptive fusion — queries classified by shape tilt BM25/semantic weights: hybrid recall@10 on the Flask gold set 0.852 → 0.926. A/B with oce eval --no-adaptive-fusion.
  • LSP-backed symbol tools — find-symbol-definition / references use tsserver, pyright, gopls or rust-analyzer when installed, falling back to the AST index; results tagged [LSP-verified].
  • Self-serve Team licenses — oce activate polar_lk_… completes checkout without support.
  • Local embeddings work out of the box — ungated all-MiniLM-L6-v2 default, no API key.
  • Docs + generated benchmarks on the Worker-served site.

0.4.x 2026-10-25 → 26

  • 0.4.5 — tokenless npm publishing (first landing), oce eval-agent end-to-end agent grading, dual-mode retrieval baselines committed fresh, pricing checkout.
  • 0.4.6 — cross-platform path-validation fix (a Windows-only path.isAbsolute escape-check bug caught by CI).
  • 0.4.7 — re-release of 0.4.6 content: the two prior versions never reached the registry (CI publish failure, then a Trusted-Publishing E404) — the release train now ships through both gates cleanly.

Full technical detail lives in the repo's CHANGELOG.md. Retrieval numbers behind these releases are on the benchmarks page.
