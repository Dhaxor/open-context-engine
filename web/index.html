Agentic workflow FAQ

What is an agentic workflow?

Software where an LLM plans, calls tools, observes results, and loops until a goal is met — instead of answering once. Read the full guide. For connecting agents to your code over MCP, see the MCP server guide.

Why is code retrieval the bottleneck?

The agent's context window is smaller than your codebase. Hybrid retrieval over an AST-aware index decides what the model actually sees — and acts on.

How do I ground Claude Code or Cursor?

Install, then one command: oce mcp install claude-code (or cursor, vscode, windsurf, claude-desktop). Step by step for Claude Code and Cursor.

Does it work offline?

Yes — local MiniLM embeddings in-process, local SQLite storage, keyword-only fallback. Nothing is sent anywhere.

Is it an alternative to Augment's context engine?

For giving agents codebase context over MCP, yes — MIT-licensed and indexed on your machine. What differs, and how it compares with Cursor, Copilot and other MCP servers.

Can agents remember things across sessions?

Yes — durable, local memory over MCP that you can read and correct. See agent memory.
