setup/claude-desktop 1.00

Ask Claude Desktop about your code

Claude Desktop can't see your repository on its own. Add Open Context Engine as an MCP server and Claude can search a local index of it — explain a module, trace a request, draft docs — while your code stays on disk.

Updated 16 Nov 2026

step 1 · 1 minInstall

npm install -g @dhaxor/open-context     # Node 22+

step 2 · 30 sAdd it to Claude Desktop

Run this in the repository you want Claude to search:

cd /path/to/your/repo
oce mcp install claude-desktop

It merges an open-context entry, pinned to this project, into Claude Desktop's config file:

OSconfig file
macOS~/Library/Application Support/Claude/claude_desktop_config.json
Windows%APPDATA%\Claude\claude_desktop_config.json
Linux~/.config/Claude/claude_desktop_config.json
 
{
  "mcpServers": {
    "open-context": {
      "command": "oce",
      "args": ["mcp", "--workspace", "/path/to/your/repo"]
    }
  }
}

step 3 · 1 minRestart Claude Desktop and verify

Quit and reopen Claude Desktop. The open-context tools appear in the conversation's tools menu. Ask "Give me a map of this codebase, then explain how authentication works" — Claude calls repo-map and codebase-retrieval, and answers with real paths.

Good questions for a desktop chat

  • "Explain the request lifecycle from the HTTP handler to the database." — retrieval follows the call graph.
  • "Where is RateLimiter defined, and who calls it?" — symbol tools answer exactly.
  • "Draft onboarding notes for this service." — the repo map gives the structure first.

For edits, use an agent that can apply them — Claude Code, Cursor, or the VS Code extension — on the same index.

Several repositories

cd ~/code/api && oce mcp install claude-desktop --name oce-api
cd ~/code/web && oce mcp install claude-desktop --name oce-web

Troubleshooting

  • No tools after restarting — Claude Desktop starts without your shell's PATH on some systems; re-run with --npx.
  • The server errors on start — run oce mcp --workspace /path/to/your/repo in a terminal to see why.
  • Undo it — oce mcp install claude-desktop --remove.
