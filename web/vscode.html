An AI agent in VS Code that shows its work

The Open Context Engine extension puts an agent in the sidebar, grounded in a local index of your workspace — with a live plan, approvals before it acts, a review of what it changed, and checkpoints you can rewind. Using Copilot instead? Give its agent mode the same index over MCP.

Updated 16 Nov 2026

Install from the Marketplace Open VSX (VSCodium, Cursor, Windsurf)

The extension

  • Approvals you choose: ask first, auto-edit (commands still ask), or full auto. The shell runs under the OS sandbox where there is one.
  • Changes you control: a changes tray after every turn — one diff editor for all of it, per-file undo, and Get review, where the agent reviews its own diff against the surrounding code.
  • Checkpoints: rewind the conversation and the files to any earlier turn — after a window reload too.
  • Fix it where it broke: Fix with Open Context agent in the light bulb on any error, and Fix Last Failed Command from the terminal.
  • Parallel sessions in their own git worktrees, with a notification when one finishes or needs you.
  • The context window, visible: what the model sees, ranked, with pin and evict — and the memories it was reminded of, which you can read, correct or forget.
  • Your MCP servers: add the ones you already use to openContext.agent.mcpServers and the agent can call them; anything that changes things asks first.

It works with OpenAI, Anthropic, Google, Ollama or any OpenAI-compatible endpoint. Indexing is local; with Ollama and local embeddings, nothing leaves the machine.

GitHub Copilot agent mode, over MCP

If Copilot is your agent, give it Open Context Engine's tools instead. From the project root:

npm install -g @dhaxor/open-context
oce mcp install vscode

That merges a server into .vscode/mcp.json, the workspace file VS Code reads:

{
  "servers": {
    "open-context": {
      "type": "stdio",
      "command": "oce",
      "args": ["mcp", "--workspace", "${workspaceFolder}"]
    }
  }
}

Commit it to share the setup with your team. For every workspace instead, oce mcp install vscode --scope user runs code --add-mcp for you. With the extension installed, Open Context: Set Up MCP for Another Tool… in the Command Palette does the same.

Then open Copilot Chat in agent mode and check the tools picker: the open-context tools — codebase-retrieval, repo-map, symbol definitions and references — are listed and can be toggled.

Requirements

  • VS Code 1.103 or newer.
  • Windows x64, macOS (Intel and Apple Silicon), or Linux x64/arm64 with glibc 2.34+. Remote SSH, WSL, Dev Containers and Codespaces work on the same platforms.
