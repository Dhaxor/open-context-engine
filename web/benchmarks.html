How to read this

keyword-only runs use BM25 alone (no embedding key, no vectors). hybrid fuses BM25 with vector similarity; since Oct 2026 the fusion weights adapt to query shape (definition-shaped queries lean BM25, paraphrases lean semantic) — the voyage rows above predate that change and are kept as the equal-weight reference. ctx-recall checks whether the gold file made it into the packed context an LLM actually receives. Gold sets are file-granular: a case passes when the gold file ranks in the top-10 unique files. Flask is an external, never-seen codebase — the honest test of a ranking change.
