An open-source alternative to Augment's Context Engine

Augment's Context Engine gives coding agents semantic search over your codebase, and it's now available to any MCP client. Open Context Engine does the same job as MIT-licensed software that indexes on your machine, needs no account, and has no per-query fees. Here's what actually differs.

Updated 16 Nov 2026

Where the difference matters

Your code stays put

With Open Context Engine, chunking, embedding and search run in a local process against a local SQLite file. Retrieved snippets go to whichever LLM your agent already talks to — nothing extra is sent anywhere. That's the property security reviews ask about, and you can verify it in the source.

No meter on retrieval

An agent can call codebase-retrieval dozens of times in one task. Locally, that costs nothing. With per-query billing, retrieval-heavy agents become a line item.

Measured in the open

Open Context Engine's retrieval quality is scored on committed gold sets — its own repository and two codebases it had never seen — and the numbers are on the benchmarks page, regenerated from the harness's reports. We haven't run Augment against those sets, so this page makes no claim about which retrieves better. Run oce eval on your own repository to judge for your code.

When Augment may fit better

  • You want a hosted service with nothing indexed or run on developers' machines — Augment's remote mode indexes from your GitHub repositories.
  • You already use Augment's agents and want one vendor for the agent and its context.

Switch in five minutes

If you're using Augment's MCP server in Claude Code or Cursor today:

npm install -g @dhaxor/open-context
cd /path/to/your/repo
oce mcp install claude-code      # or: cursor · vscode · windsurf · claude-desktop

Your agent gets codebase-retrieval — the same tool name — plus repo-map, symbol definitions and references, and memory tools. Setup guides: Claude Code · Cursor · VS Code. More tools compared on the comparison page.

Frequently asked questions

Is there an open-source alternative to Augment's Context Engine?

Open Context Engine: MIT-licensed, indexes on your machine (AST-aware chunks, BM25 + vectors, a code graph), and serves MCP clients such as Claude Code, Cursor, VS Code, Windsurf and Claude Desktop — no account for individual use.

Where does Augment's Context Engine index code?

Augment's docs say workspace indexing uploads your codebase to its cloud, where its semantic search backend stores the embeddings.

Is Open Context Engine better than Augment?

We haven't benchmarked Augment on our gold sets, so we don't claim that. The differences above are structural: license, where code is indexed, accounts and pricing.
